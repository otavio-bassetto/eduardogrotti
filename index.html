01 / VISÃO GERAL

O projeto, em poucas palavras.

Docker permite que a aplicação e suas dependências sejam empacotadas em uma imagem reproduzível.

Assim, o projeto pode ser iniciado de maneira previsível em diferentes máquinas, evitando o clássico “funciona só no meu computador”.

▣

Ambiente isolado

Execute a aplicação em um container com suas dependências organizadas.

03 / COMEÇAR

Pronto para executar?

Com Docker instalado, abra o terminal na pasta do projeto.

BUILD

Construir a imagem

docker build -t minha-app .
RUN

Executar o container

docker run -p 8080:80 minha-app
LIST

Ver containers ativos

docker ps

* Ajuste a porta e o nome da imagem de acordo com o Dockerfile do seu projeto.
